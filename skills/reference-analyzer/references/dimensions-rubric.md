# Visual and Motion Analysis Rubric

Use this reference when inspecting accessible visual media to classify observations by dimension without conflating observable structure with interpretation.

## Dimensions

| Dimension       | Direct Observation Examples                                                           | Subjective Interpretation Examples                          |
| --------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `composition`   | Off-center focal block, ~60% open margin above fold, 3-column alignment rail          | Quiet architectural tension, deliberate editorial restraint |
| `color`         | Deep charcoal ground (`#181A1F`), warm cream foreground, single terracotta accent bar | Grounded industrial warmth punctuated by focused urgency    |
| `lighting`      | Hard directional key from upper left, deep falloff into shadow, crisp rim separation  | High-drama sculptural mood emphasizing surface texture      |
| `typography`    | High contrast between oversized display title and compact uppercase micro-caption     | Authoritative magazine cadence                              |
| `camera`        | Continuous slow push-in over 4 seconds, static locked tripod close-up                 | Patient anticipation before product reveal                  |
| `pacing`        | Cut durations between 2.5s and 4.0s, zero jump cuts                                   | Contemplative luxury rhythm                                 |
| `motion`        | Decelerated cubic-out settle with minimal overshoot                                   | Tactile mechanical precision                                |
| `transitions`   | Graphic match-cut aligning circular silhouette across consecutive shots               | Seamless thematic continuity                                |
| `storytelling`  | Opens on material texture before revealing full object                                | Craft-first narrative arc                                   |
| `emotionalTone` | Restrained contrast, uncluttered soundscape/frame                                     | Calm confidence                                             |
| `technical`     | Verified dimensions `600x800`, MIME `image/png`, file size                            | Suitable for portrait print or hero card aspect ratio       |

## Evidence Types

- `technical_metadata`: Verifiable file header, pixel dimensions, codec, or duration.
- `user_observation`: Directly described by the human user.
- `model_observation`: Visually verified by a capable vision analyzer that actually inspected the image/video frames.
- `verified_observation`: Cross-checked by human review.
- `user_interpretation` / `model_interpretation` / `uncertain_interpretation`: Meaning, emotional effect, or intent inferred from observations.
